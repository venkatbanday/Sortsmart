# SortSmart: Postcode to Cage Finder and Dock Checklists

A free, offline-friendly toolkit for parcel networks, FMCG, 3PL, retail and e-commerce distribution (works for any operator).

## Files
- `sortsmart_app.html`: open in any browser, no internet or install needed.
- `sortsmart_offline.xlsx`: the same lookup, checklists and savings model in Excel.

## What it does
1. **Finder**: type or scan a postcode, see the cage, lane, dock and service at once.
2. **Manage codes**: add, edit or delete codes (code, area, cage, lane, dock, service). Import or export CSV.
3. **Process**: proposed flow, dock/ramp/conveyor diagram, before and after.
4. **Checklists**: dock, ramp, conveyor, sortation, safety, FMCG. Tick, track progress, print.
5. **Savings**: estimate hours and cost saved. Default numbers are assumptions; use your own.

## Excel use
Type a postcode in the yellow cell on `Lookup`. Edit codes on `Postcode Map` (up to row 1000). Tick `Y` on `Checklists`.

## Notes
- The 50 sample codes and cage numbers are illustrative only.
- The HTML app keeps data in the page only. Export CSV to save your list.
- Free to share. No sign-up, no ads, no data collected.
